# REQUIREMENTS.md — Auto Zap (ARIA) — Milestone v1.0 (Archived)

## v1 Requirements (ALL COMPLETED)

### CORE — Motor de Mensagens & IA

- [x] **CORE-01**: Bot recebe mensagens de clientes via WhatsApp e envia respostas automáticas usando Claude API (migrado para OpenAI GPT-4o-mini com sucesso)
- [x] **CORE-02**: Bot detecta idioma da mensagem (ES/PT/EN) e responde no mesmo idioma de forma natural
- [x] **CORE-03**: Bot mantém contexto de conversa por sessão — histórico das últimas N mensagens para respostas coerentes
- [x] **CORE-04**: Bot encaminha conversa para atendente humano quando não sabe responder ou quando cliente solicita explicitamente
- [x] **CORE-05**: Identidade ARIA configurável — nome, personalidade, empresa representada, regras de negócio (implementada como Samantha)
- [x] **CORE-06**: QR Code de autenticação WhatsApp com reconexão automática em caso de queda

### PROD — Catálogo & Estoque

- [x] **PROD-01**: Cliente pode consultar produtos por nome, SKU ou categoria — bot busca no Google Sheets e responde com detalhes
- [x] **PROD-02**: Cliente recebe preço em PYG e R$ (automático) e status de disponibilidade do produto consultado
- [x] **PROD-03**: Bot informa restrições do produto (requiere receta, notas especiais) quando relevante

### SUC — Filiais

- [x] **SUC-01**: Cliente pode perguntar sobre filiais — bot retorna endereço, horário, telefone e se aceita WhatsApp
- [x] **SUC-02**: Bot lista filiais disponíveis quando cliente pergunta sobre localização geral

### SVC — Serviços

- [x] **SVC-01**: Cliente pode consultar serviços disponíveis — bot retorna descrição, preço (PYG/R$), requisitos e duração/modalidade

### FAQ — Perguntas Frequentes

- [x] **FAQ-01**: Bot busca perguntas frequentes por tags e similaridade semântica com a pergunta do cliente
- [x] **FAQ-02**: Respostas do FAQ são contextualizadas pelo Claude/GPT — não são cópia/cola robótico

### LEAD — Registro de Interesse

- [x] **LEAD-01**: Bot registra interesse do cliente (nome, telefone, produto/serviço, data) no Google Sheets quando cliente demonstra intenção de compra
- [x] **LEAD-02**: Bot confirma o registro ao cliente com mensagem de confirmação

### HIST — Histórico de Conversas

- [x] **HIST-01**: Cada conversa finalizada é registrada no Google Sheets (telefone, data/hora, resumo do atendimento)
